## Design Context

### Users
Final-year CS students at UNIOSUN Osogbo, Nigeria. Using the app to practise and revise course material via Socratic questioning. Context: studying, late-night revision, high-stakes (thesis evaluation cohort). Job: upload materials, ask questions, track mastery scores per topic.

### Brand Personality
Academic · Trustworthy · Focused

### Aesthetic Direction
Warm & academic — inspired by Notion. Slightly warm off-white backgrounds, Inter font, indigo/blue-violet accent for interactive elements, refined spacing, rounded cards. Both light and dark mode. Not playful, not enterprise-dark, not generic SaaS blue.

### Design Principles
1. **Clarity over decoration** — every element earns its place; no gradients, glassmorphism, or decorative noise
2. **Indigo as the single accent** — use `text-primary` / `bg-primary` / `bg-primary/10` consistently; never hardcode hex
3. **Typography carries weight** — headings at `text-2xl font-bold`; section labels at `text-xs font-semibold uppercase tracking-widest text-muted-foreground`
4. **Active states are unambiguous** — nav active link: `bg-primary/10 text-primary font-medium`; always use `usePathname()` for detection
5. **Warm but not soft** — cards have hover shadows (`hover:shadow-md transition-shadow`); empty states have icon + CTA, not just a text message

### Stack
Next.js 16, shadcn/ui (radix-nova, neutral base, CSS variables), Tailwind CSS, Inter via `next/font/google`

### Token Quick Reference
- Font: `--font-inter` (Inter, loaded via next/font)
- Primary: `oklch(0.46 0.19 264)` light / `oklch(0.72 0.15 264)` dark
- Background: `oklch(0.99 0.004 90)` light (warm off-white)
- Radius: `0.75rem`
